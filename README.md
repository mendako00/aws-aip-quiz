# AWS AIP 模擬試験 演習ツール

AWS Certified AI Practitioner (AIP) の学習用に作った、ブラウザだけで動く問題演習ツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・サーバー不要）。

GitHub Pages で公開している場合は、公開URLにアクセスしてください。

## 機能

- 問題を1問ずつ表示（単一選択・複数選択の両対応）
- 「回答する」で即時に正誤判定（正解=緑 / 誤答=赤でハイライト）
- 問題番号ナビで正誤を色分け表示・ジャンプ
- 進捗バーと正解数の表示
- 成績画面（正答率・一問ごとの正誤一覧）
- シャッフル出題
- 間違えた問題だけ復習
- 進捗の自動保存（ブラウザの localStorage）

## 構成

```
.
├─ index.html         アプリ本体（HTML/CSS/JS 一体）
└─ data/
   └─ questions.js    問題データ（window.QUIZ_DATA）
```

問題を追加するときは `data/questions.js` の配列に要素を足します。

## 注意

- 学習用の個人プロジェクトです。
- 問題文は学習のために書き起こしたものです。元画像（スクリーンショット）はリポジトリに含めていません。
